# Tesis de licenciatura
## Captura de movimiento corporal en 3D con visión estéreo: análisis de movimiento en la terapia física, y aplicación en Python/Unity

Se desarrollo una aplicación Python de escritorio utilizando el framework CustomTkinter y encapsulada con Docker, la cual realiza un análisis del movimiento corporal en 3D a partir de dos videos pregrabados de una persona desde diferentes ángulos y de la visión estéreo.

El análisis del movimiento consiste en visualizar ángulos articulares de una persona a lo largo del tiempo.

Además, se tiene un primer enfoque a las posibilidades que se pueden alcanzar con el uso de la visión estéreo, así como su posible uso para la rehabilitación física mediante juegos interactivos 3D creados en Unity que responden al movimiento corporal del paciente.
